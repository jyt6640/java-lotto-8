## 📋 **기본 기능 목록**

---

간단한 로또 발매기를 구현한다.

- [X] 로또 번호의 숫자 범위는 1~45까지이다.
- [X] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- [X] 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- [X] 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - [X] 1등: 6개 번호 일치 / 2,000,000,000원
    - [X] 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - [X] 3등: 5개 번호 일치 / 1,500,000원
    - [X] 4등: 4개 번호 일치 / 50,000원
    - [X] 5등: 3개 번호 일치 / 5,000원
- [X] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- [X] 로또 1장의 가격은 1,000원이다.
- [X] 당첨 번호와 보너스 번호를 입력받는다.
- [X] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- [X] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

### **입출력 요구 사항**

**입력**

- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

```
14000
```

- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

```
 1,2,3,4,5,6
```

- 보너스 번호를 입력 받는다.

```
7
```

**출력**

- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```

- 당첨 내역을 출력한다.

```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

```
총 수익률은 62.5%입니다.
```

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.

```
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

- **실행 결과 예시**

```
구입금액을 입력해 주세요.

당첨 번호를 입력해 주세요.

보너스 번호를 입력해 주세요.

당첨 통계
---
```

- [X] 문자열을 int로 변환
- [X] 구입 금액이 int 범위 내인지 확인

#### 당첨 번호 추출

- [X] 분리된 각 번호의 앞뒤 공백 제거
- [X] List<Integer> 형태로 반환

#### 보너스 번호 추출
- [X] 문자열을 int로 변환
- [X] 보너스 번호가 int 범위 내인지 확인

#### 도메인 객체 생성
##### 로또(Lotto) 객체 생성
- [X] 로또 번호가 6개인지 확인
- [X] 로또 번호에 중복이 없는지 확인
- [X] 로또 번호가 1~45 범위 안에 있는지 확인
- [X] 로또 번호 오름차순 정렬
- [X] 검증 통과 시 로또 번호를 필드로 저장

##### 일급 컬렉션(Lottos) 생성
- [X] 로또가 최소 1장 이상인지 확인
- [X] Lotto 객체들을 List로 관리하는 Lottos 일급 컬렉션 생성

##### 당첨 번호(WinningLotto) 객체 생성
- [X] 당첨 번호 6개 관리
- [X] 보너스 번호가 당첨 번호와 중복되지 않는지 확인

##### 보너스 번호(BonusNumber) 객체 생성
- [X] 보너스 번호가 1~45 범위인지 확인
- [X] 보너스 번호가 당첨 번호와 중복되지 않는지 확인

##### 등수(Rank) Enum 생성
- [X] 1등: 6개 일치 / 2,000,000,000원
- [X] 2등: 5개 일치 + 보너스 / 30,000,000원
- [X] 3등: 5개 일치 / 1,500,000원
- [X] 4등: 4개 일치 / 50,000원
- [X] 5등: 3개 일치 / 5,000원
- [X] 낙첨: 2개 이하 / 0원

##### 돈(Money) 객체 생성
- [X] 금액을 기반으로 로또 구매 개수 계산
- [X] 구입 금액이 1,000원 이상인지 확인
- [X] 구입 금액이 100,000원 미만 인지 확인
- [X] 구입 금액이 1,000원 단위인지 확인
- [X] 수익률 계산 (총 당첨금 / 구입 금액 × 100)

#### 로또 번호 생성
- [X] 1~45 범위의 랜덤 번호 6개 생성
- [X] 중복 없이 생성
- [X] 구입 금액에 따라 여러 장 생성

#### 당첨 판별
- [X] 로또 번호와 당첨 번호 비교
- [X] 일치하는 개수 계산
- [X] 보너스 번호 포함 여부 확인
- [X] 일치 개수와 보너스 여부로 등수 판별

- [X] 각 등수별 개수 계산
- [X] Map<Rank, Integer> 형태로 반환

#### 수익률 계산
- [X] 총 당첨금 계산 (각 등수 당첨금 × 개수의 합)

### 🖥️ 출력
#### 로또 구매 시
- [X] "n개를 구매했습니다." 출력
- [X] 각 로또 번호를 오름차순으로 정렬하여 출력

#### 당첨 통계 출력 시
- [X] "당첨 통계" 출력

  - [X] "5개 일치 (1,500,000원) - n개"
  - [X] "5개 일치, 보너스 볼 일치 (30,000,000원) - n개"
  - [X] "6개 일치 (2,000,000,000원) - n개"
